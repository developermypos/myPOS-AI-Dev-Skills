# myPOS API Gateway — References Index

> Docs: https://developers.mypos.com/sdks/api-gateway-typescript-sdk

## Reading Order

1. `references/partner-portal.md` — **Start here if you haven't registered yet.** Partner Portal setup, creating an integration, getting credentials.
2. `references/authentication.md` — OAuth2 flow, session tokens, SDK initialization.
3. Open exactly one API group reference based on what you need:
   - `references/banking-api.md` — accounts, transactions, statements
   - `references/ecommerce-api.md` — payment links, payment buttons, payment requests
   - `references/epos-api.md` — POS payments, terminals, refunds, reversals
4. `references/error-handling.md` — result pattern, checking success, surfacing errors.
5. `references/testing.md` — Demo Partner Portal, sandbox credentials.
