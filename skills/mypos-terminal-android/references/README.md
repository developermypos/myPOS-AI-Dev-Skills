# myPOS Android SDK — References Index

> Docs: https://developers.mypos.com/sdks/android-sdk
> Integration context: https://developers.mypos.com/in-person-payments/paying-counter

## Reading Order

1. `references/setup.md` — **Start here.** Maven dependency, permissions, `POSHandler` initialization.
2. `references/connection.md` — Connect to the terminal (Bluetooth / USB / TCP-IP).
3. Open exactly one operation reference based on what you need.
4. `references/testing.md` — Demo Debug POS device setup.
