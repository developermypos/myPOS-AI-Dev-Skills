# myPOS Embedded Checkout SDK — References Index

> Docs: https://developers.mypos.com/sdks/embedded-sdk

## Reading Order

1. `references/setup.md` — **Start here.** npm or CDN install, container div.
2. `references/card-payment.md` — standard embedded form with SDK-rendered Pay button.
3. `references/deferred-payment.md` — if you need your own Pay button.
4. `references/webhooks.md` — always implement server-side IPN verification.
5. `references/testing.md` — sandbox and test cards.

## All References

| File | Use when... |

| `setup.md` | First-time SDK setup |
| `card-payment.md` | Embed the form with SDK-rendered Pay button (`createPayment`) |
